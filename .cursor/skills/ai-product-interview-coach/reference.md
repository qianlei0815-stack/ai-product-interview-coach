# Reference Guide

## Score rubric

| Dimension | 1 | 3 | 5 |
| --- | --- | --- | --- |
| Problem framing | Jumps to a feature | Names a plausible user and goal | Defines a segment, pain, constraints, and success criterion |
| Product judgment | Lists undifferentiated ideas | Prioritizes with partial rationale | Makes a clear, user-led choice and explains trade-offs |
| Analytical rigor | Uses unsupported claims | Identifies relevant metrics | Builds a metric tree, tests hypotheses, and states guardrails |
| Execution | Ignores delivery realities | Names stakeholders and milestones | Anticipates risks, dependencies, sequencing, and ownership |
| Communication | Hard to follow | Mostly structured | Concise, decisive, and easy to interrogate |

## Recommended answer structures

- **Design:** clarify -> target user -> pain point -> goal -> options -> prioritization -> MVP -> metrics -> risks.
- **Metrics:** clarify metric definition -> metric tree -> hypotheses -> segmentation -> diagnosis -> experiment -> guardrails.
- **Strategy:** objective -> market/user -> alternatives -> strategic choice -> economics -> execution -> risks.
- **Behavioral:** situation -> task -> actions -> result -> reflection.

## Question seeds

### Product design

- Design a feature that helps first-time managers give better feedback.
- Improve the onboarding experience for a professional collaboration tool.
- How would you make an AI writing assistant trustworthy for a regulated industry?

### Metrics

- Weekly active users fell 12% after a new onboarding flow. How would you investigate?
- A team wants to optimize clicks, but revenue and retention are flat. What would you measure instead?

### Strategy

- Should a collaboration product launch a free tier in a new market?
- A well-funded competitor copied the core feature. What changes, if anything?

### Behavioral

- Tell me about a time you changed a roadmap after learning you were wrong.
- Describe a disagreement with engineering or design and how you resolved it.

## Example follow-ups

- What decision would change if that assumption were false?
- Which user segment would you deprioritize, and why?
- What would be your first leading indicator after launch?
- What is the smallest experiment that could disprove your approach?
- Who could block this plan, and how would you bring them along?
